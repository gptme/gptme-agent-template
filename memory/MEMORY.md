# Auto Memory

One-line pointers to memory files live here — this index is loaded into context
each session. Keep each memory as its own file; add a single pointer line per
memory, in the form:

```
- [Title](the-memory-file.md) — one-line hook
```

See the `## Memory` section in AGENTS.md for how memory is wired and why this
directory exists even on a fresh fork.
